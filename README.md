# Tic Tac Toe (Python Console Game)

This is a simple command-line Tic Tac Toe game built in Python.  
Two players can play the game on the same device by taking turns to enter their moves.  
The project focuses on basic Python logic, condition checking, and user interaction.

## 📌 Overview

The game allows two players (X and O) to play Tic Tac Toe on a 3×3 board.  
Each position on the board is represented by a number (0–8).  
Players choose a position, and the board updates until someone wins or all positions are filled.

## 🎮 Features

- Two-player local gameplay  
- Number-based board selection  
- Automatic win detection  
- Clean and simple board display  
- Replay handled through program restart

## 🛠 Technologies Used

- **Python 3**
- **Basic conditional logic**
- **Functions for reusability**
- **Simple console input/output**

## 🧪 How to Play / Testing Instructions

1. The board shows numbers from 0–8  
2. Each number represents a position  
3. On your turn, type the number where you want to place your symbol  
4. The game checks for a win after every move  
5. Game ends when:  
   - X wins  
   - O wins  
   - Board is full (draw)
