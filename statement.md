# Project Statement – Tic Tac Toe (Python Console Game)

## 📌 Problem Statement
Many beginners learning Python need small interactive programs to practice logic, functions, and condition checking.  
Tic Tac Toe is a classic two-player game that is simple to understand and works well as a beginner-level project.  
The goal of this project is to create a playable version of the game using only Python and the console, without any external libraries or complex setup.

---

## 🎯 Scope of the Project
The project includes the basic gameplay loop, board display, input handling, and win checking for a 3×3 Tic Tac Toe board.  
It is fully menu-less and works by accepting number-based player inputs.  
The system supports:
- Two players (X and O)
- Number-based board positions
- Turn-by-turn game flow
- Win and draw detection  
The scope is limited to console gameplay and does not include AI opponent or GUI.

---

## 🧑‍🤝‍🧑 Target Users
- Python beginners  
- Students practicing conditional logic  
- Anyone wanting to play a simple terminal-based Tic Tac Toe game  
- Users who prefer lightweight, no-installation programs  

---

## ⭐ High-Level Features
- Text-based 3×3 game board  
- Clean board display that updates after each move  
- Valid move handling  
- Detection for:
  - Row wins  
  - Column wins  
  - Diagonal wins  
- Draw condition when the board is full  
- Simple and easy-to-read code structure
